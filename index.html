01 SERVERS

A partner list. Not a browser window full of ads.

The Servers page is a grid of cards for the handful of servers the launcher author actually plays on. Each card is pinged for real — player count, latency, MOTD and the version the server runs — so a quiet server shows a low number and a dead one says offline instead of pretending.

  • Nobody can add a server from inside the launcher — the list ships in the app, curated by hand.
  • Pin up to eight partners into quick slots and join in one click with the profile you already selected.
  • No invented population — when the ping fails, the card shows the failure and the time it was checked.

LightingMC is the only partner in this build. Cards live in one source file, so a card cannot exist for a server that does not.

02 PROFILES

One card per identity, with the version it will actually launch.

Each profile gets a cover, the loader line, the exact Minecraft version and how many mods and packs sit in that instance — counted from the folder on disk every time the page opens. The selected profile carries the ring; the dashed tile makes a new one, offline name or Microsoft.

  • Play launches the version named on the card, with that profile's memory, HUD layout and skin.
  • "Manually modified" is read from disk — drop a jar or a pack into the instance and the card says so.
  • Mods and Resource packs open the real thing: the manager, and the instance's own folder.

Offline profiles are labelled unauthenticated on the card. Microsoft sign-in happens in your browser — the launcher never asks for the password.

03 LAUNCH

One grey screen, one bar, and the truth underneath it.

While Minecraft boots, the launcher gets out of the way: the mark, the wordmark and a single thin bar. The caption is the engine's own status line, and the bar is a real percentage whenever something is actually downloading — verification, repair, a runtime the version needs.

  • No fake 37%. With nothing to measure the bar sweeps and says what it is waiting for.
  • It closes when the window appears — "running" means the game is up, not that a process exists.
  • Esc hides it, nothing else: hiding the splash never cancels the launch or kills Java.

A launch that is refused — not enough RAM, no usable Java — closes this screen and tells you why instead of spinning forever.

The long wishlist, marked honestly

What 0.9.5 actually does — and what it does not.

Every launcher in this corner of Minecraft has a feature list a mile long. Here is the whole list this project is measured against, with each line labelled by what the shipped build does today. Nothing on this page is marked built unless it works in 0.9.5 on a real install.

builtpartial plannednot planned
Version manager & per-version Java built

Vanilla straight from Mojang's manifest plus Fabric, Quilt, Forge and NeoForge. The Java major comes from the version's own metadata, and a Temurin runtime is downloaded when the machine does not have it — that is what makes 26.x work at all.

Offline & Microsoft accounts built

Microsoft sign-in runs PKCE loopback in your own browser and stores the token in the OS keychain. Offline profiles work with no account and are labelled unauthenticated.

Mod manager built

Modrinth search with SHA-512 checked downloads, loader/dependency/duplicate checks before launch, enable-disable per instance and a backup of the mods folder before install.

PvP HUD modules built

FPS, CPS, keystrokes, armour and durability, potion timers, coordinates, direction, session timer, scoreboard, sprint indicator, zoom and ping. Right Shift opens the editor in game; rebindable in Minecraft's controls.

Crosshair customiser built

Style, colour, scale, gap and thickness, drawn by the bridge mod. Purely visual — it never changes hit detection.

Skins, capes & cosmetics built

64×64 skin validation and preview before saving. Your skin and cape show on your player in-game on Minecraft 1.20.1 and 1.21.11 (Fabric + Fabric API) - offline profiles included, plus a built-in Neon Volt skin. 0.9.5 adds an optional gold ⚡ badge in front of your own name tag, and an alternative Orbit Home layout - a big PLAY hex, live partner-server pings and quick settings, with the classic Home kept. Other players see them only through the optional relay; on vanilla servers they see the server-side look.

Real FPS telemetry built

FPS, frame time and 1% lows sampled from the running game. When the bridge is missing the launcher says the numbers are unavailable rather than estimating them.

Partner server list built

Curated cards with a real Minecraft ping, pinned quick slots, and no self-serve add button anywhere in the UI.

Config backups before edits built

options.txt and mods folders are copied aside before the launcher changes a single line, and restore puts them back.

Crash detection & self-repair built

Crash signatures with a plain-English cause, plus one automatic repair-and-relaunch when a truncated jar is the reason.

Resource packs partial

The launcher counts the packs in an instance and opens the folder for you. Browsing and enabling packs inside the app is not shipped yet.

Sodium / performance mod stack partial

Presets explain which mods help and flag Sodium ↔ OptiFine conflicts, but nothing is bundled or auto-installed — that stays your choice.

Resource-pack cache planned

Not in this build. Packs are read from the instance folder each launch.

Fast quit planned

Closing the game still goes through Minecraft's own shutdown; there is no forced process kill yet.

Freelook planned

Planned as an optional bridge feature, off by default. Nothing in the current build rotates the camera for you.

Fullbright, motion blur, saturation planned

Visual toggles of that kind belong in a renderer mod; the launcher does not patch the game's shaders today.

Minimap & waypoints planned

Not built in — Xaero's and similar install cleanly through the mod manager in the meantime.

Chat customisation planned

Prefixes, timestamps and filters are not implemented; chat is untouched vanilla.

Discord Rich Presence planned

No Discord integration ships in 0.9.5. If it lands it will be opt-in and will never show your server address.

Extra languages, including Arabic planned

The interface is English-only today, and it is not an RTL layout yet. Translating before the layout can mirror would be dishonest.

Replay recording planned

Not built in. The Replay Mod installs and runs through the mod manager.

Changing reach, hitbox or knockback NOT PLANNED

Those are cheats and this launcher will not implement them, in any mode. The HUD can show your own reach distance and hitbox as a readout — it does not alter combat.

Statuses describe build 0.9.5 (Lighting-Launcher-Setup-0.9.5-win-x64.exe). Planned means designed and not written; partial means it works but not the whole way. Reach and hitbox changes will never ship — that is a fairness line, not a roadmap gap.

Is it really free?+

Yes. No store, no keys, no subscription, no "premium" skins. Game files come straight from Mojang's public version manifest, so there is nothing for us to resell.

Do you ever see my Microsoft password?+

No. Sign-in opens Microsoft's own page in your browser and returns to a listener this launcher opened on 127.0.0.1 — authorization code with PKCE, the supported desktop pattern. The launcher only receives the Xbox Live token Microsoft issues, and it is written to the OS secure store. If the Azure app is missing the http://localhost redirect, you get the exact AADSTS50011 message and a device-code fallback instead of a spinner that never ends.

Can I play without signing in?+

Yes. Offline profiles are first-class and clearly labelled unauthenticated. They work in single-player and on servers with online-mode=false. They will never get you into a Microsoft-authenticated server, and they never claim to be somebody else's account.

Which versions can it launch?+

Vanilla releases and snapshots from Mojang's manifest — rules for OS, architecture and features are resolved per version so the classpath matches what the game expects. Fabric, Quilt, Forge and NeoForge are installed through the mod manager. Java 8, 16, 17 and 21 are detected per version, and you can point at your own JDK.

Does it actually boost FPS?+

It applies renderer options and Java/G1 flags you could set yourself — per instance, after backing up options.txt — and it refuses to disable Windows security features or push obsolete flags into a modern JVM. The large gains people talk about come from performance mods; install those through the mod manager. Every number on the FPS page is read from the running game. If nothing is running, you get an em dash.

Will other players see my cape or cosmetics?+

Only where our bridge mod is installed on both sides. On a vanilla server nobody else sees them. Local cosmetics work with no account at all; shared cosmetics need the bridge on both clients and a server that relays the manifest. We won't claim universal visibility on vanilla servers.

Are there PvP cheats in it?+

No. The HUD is client-side stats and cosmetics, and the single mixin we ship counts clicks. There is no kill aura, aimbot, reach, anti-knockback or packet exploit — not present and not planned. Anti-cheat can flag any client mod, so check the server's rules first.

Windows only? Is the installer signed?+

Windows 10/11 x64, shipped as an NSIS installer. The build is not code-signed, so SmartScreen may warn on first run — compare the SHA-256 published below with the file you downloaded. macOS and Linux are not supported.

What if the game doesn't start?+

Every launch re-checks the size and SHA-1 of the jars it is about to load and re-downloads only the broken ones — an interrupted download used to leave a truncated jar that made Minecraft exit with NoClassDefFoundError while every file "existed". If the game still dies with a library error, the launcher repairs and relaunches once by itself, then tells you exactly what is wrong in Logs & Diagnostics.

Can I add my own servers?+

No — the server list is curated with the build. Every card on the Servers page is one the launcher ships, so what you see is what exists. Join launches the game and connects straight in; the server still applies its own whitelist and account rules.

Where does my data go?+

Settings, skins, HUD layouts and logs stay in the launcher's own userData folder on your PC. No analytics upload. Network calls are Mojang's manifest and assets, Java runtime downloads, server pings, Microsoft's sign-in endpoints when you choose to sign in — and, since 0.9.3, crash reports: when Minecraft crashes, the launcher can post the crash cause, versions and the last bit of the game log to the support Discord (tokens, UUIDs and your PC username stripped first). It is on by default and can be switched off any time in Settings → Support & Bug Reports.

Where do I get help or report a bug?+

The Discord server — discord.gg/wB6j6PECNZ. devaru007 reads the support channel. Inside the launcher, the Discord button sits in the left rail on every screen, and Logs & diagnostics → Send to Discord (or Settings → Support & Bug Reports) files a report with the crash diagnosis and log already attached, so you rarely need to copy-paste anything.
